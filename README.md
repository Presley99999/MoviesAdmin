This Project is a Movie review website similar to rotten tomatoes.
The project will be split up into four different sprints.
when each sprint is complete i will update this page to add details of the next sprint,
and will add more detail to the description of the completed sprint.

Sprint 1:

Sprint 1 of the movie review website will include Building the admin view of the website using an ASP.net core MVC called "MoviesAdmin."
in this sprint I will need to let the apps users create, read, update and store movie data that is stored in a database.
this date will include the movie title, the description of the movie, it's age rating (G, PG, PG-13, R), how long it is and what year it got released.
the admin app will include a summary list of all the movie sorted by release date and there need to be a button to add a new movie or view, update or delete an already existing movie.
the app will have personal branding to distinguish itself from other reviewing websites.
